# 🧾 Personal Expense Tracker

A simple web app concept to help people **track their personal spending** — my **first Information Systems / Business Analysis project**.

> **Status:** Concept and planning stage.

## 🧩 The Problem

Many students and young professionals don't know where their money goes each month. Banking apps show transactions, but they rarely make it easy to see spending by category or to stick to a budget.

## 👤 Target Users

- University students managing a limited budget
- Young professionals starting to plan their finances

## 📋 Planned Requirements

| Priority | Requirement |
| --- | --- |
| Must have | Add, edit and delete expenses with amount, date and category |
| Must have | See a monthly summary of total spending |
| Should have | View spending broken down by category |
| Should have | Set a monthly budget and see how much is left |
| Could have | Charts showing spending trends over time |
| Could have | Export expenses to CSV |

## 🧭 Business Analysis Focus

This project is a space to practise core BA skills:

- Writing a clear **problem statement** and defining **target users**
- Turning user needs into **prioritised requirements** (MoSCoW)
- Sketching **user flows** and simple **wireframes** before building
- Defining what **success** looks like for the user
